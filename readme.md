# CSE 586 Project 1

## Instructions

- Download the required data files from Canvas and place them in the parent folder prior to running any scripts.
- Create your conda environment using the environment.yml file provided
- In order to look at our results, please run `eval.py`. Ensure the `best_model` folder exists.
- Alternatively, run `eval_plot.py` to also get the generated plot for visualizing divergence of predictions and baselines from the ground truth, using MPJPE loss.
- To train the model, run `train_transformer.py`
- Another visualization, showing the body pose meshes for the worst and best predictions of the transformer against the ground truth, can be found in `intermediate_demo.ipynb`
